# 🎭 GS Arts Center 3D 좌석 시야 뷰어 (v5)

본 프로젝트는 Shapespark 3D 가상 공간 솔루션과 2D 대화형 좌석 배치도를 유기적으로 연동한 **웹 표준 3D 공연장 좌석 시야 시뮬레이션 시스템**입니다. 관객이 예매 전 실제 관람 시야를 고해상도 3D로 미리 체험할 수 있도록 고도화된 UI/UX 환경을 제공합니다.

---

## 🌟 주요 기능 및 핵심 기술

### 1. 2D-3D 인터랙티브 좌석 시야 연동
- **2D 배치도 ↔ 3D 뷰어 동기화**: 2D 좌석 배치도에서 좌석 클릭 시 Shapespark 3D 카메라 뷰가 해당 관람 좌석 위치로 즉시 부드럽게 이동합니다.
- **1층 / 2층 좌석 완전 지원**: 1층 및 2층 각 블록(A, B, C)의 실제 좌석 정보가 정밀하게 매핑되어 있습니다.

### 2. 동적 무대 시선 연산 (Stage LookAt Math)
- **3D 좌표 기반 카메라 각도 자동 연산**: 자유 관람 위치 및 다양한 좌석 시점에서 무대 중앙 목표 좌표(`vec_LookAt`)와의 상대 거리 차이를 삼각함수(`Math.atan2`)로 실시간 계산하여, 시선 방향(`Yaw`, `Pitch`)을 최적의 무대 각도로 자동 고정합니다.

### 3. 무대 장치 및 OP석 가시성 토글 (Stage & OP Control)
- **무대 커튼 상태 변경 (`btn_stage_change`)**: 3D 모델 내 무대 커튼 노드들(`curtain_1~3`)의 표시/숨김 상태를 단계별로 조절하여 공연 연출별 무대 시야를 시뮬레이션합니다.
- **오케스트라 피트 변경 (`btn_op_change`)**: OP석 벽체, 의자, 바닥 노드(`op_chair`, `op_wall`, `op_floor`)의 가시성을 변경하여 OP석 유무에 따른 공간감을 확인합니다.

### 4. 지능형 좌석 네비게이션 & 인터락 (Interlock System)
- **더미 좌석 자동 건너뛰기**: 배치도 구조상 관람이 불가능하거나 비어있는 더미 좌석(`Seat_Type: "none"`)은 이전/다음 버튼 클릭 시 자동으로 건너뜁니다.
- **연속 렌더링 튐 방지**: 빠른 연쇄 클릭 시 3D 카메라 연산 오버헤드를 막기 위해 1.2초 타임아웃 락(`isNavigating`)이 구동됩니다.

### 5. 타임라인 기반 UI 시퀀스 초기화
- **정밀 시퀀스 애니메이션 (`initUIOnSceneReady`)**: 3D 씬 로딩 완료 후 `T=0ms` ➡️ `T=1000ms` ➡️ `T=1500ms` ➡️ `T=1550ms` 단계별 타임라인에 따라 로딩 배너 페이드아웃, 오버레이 표출, 3D 커튼 노드 초기화가 매끄럽게 진행됩니다.

| :--- | :--- |

| **`gs_arts_center_ui.js`** | Shapespark Viewer API 연동, UI 컨트롤, 카메라 시선 계산, 시퀀스 초기화 스크립트 |

```bash
# 2. CSV -> JSON/JS 변환 파이썬 스크립트 실행

```

## 🚀 로컬 실행 방법

CORS 제약 없이 로컬 환경에서 3D 뷰어와 데이터 연동을 테스트하려면 아래와 같이 실행합니다.

```bash
# 방법 1: 로컬 실행 배치 파일 구동
.\run_server.bat

# 방법 2: 파이썬 로컬 HTTP 서버 구동
python -m http.server 8000
```

실행 후 웹 브라우저에서 `http://localhost:8000` (또는 지정된 포트)로 접속하여 시뮬레이션을 확인합니다.
